Setup in 3 steps

  1. Download & unzipExtract the ZIP to a folder you keep, like Documents\Kai.
  2. Run “Setup Kai.cmd”Installs Kai's packages privately in %LOCALAPPDATA%\Kai. No admin needed.
  3. Open “Kai.exe”Move your pointer to the top centre of the screen. That's it.

Private by design

Your clipboard is yours.

  • Notes, clipboard history and Shelf live in %LOCALAPPDATA%\Kai on your PC.
  • No account, no analytics, no telemetry. File conversion and OCR run locally.
  • Password-manager copies are skipped, and history can be paused or cleared any time.
  • Network only for optional lyrics (LRCLIB) and optional Spotify sign-in.

Questions

Is Kai free?

Yes. Kai is a free, open-source personal project by RicoMitra. There is no paid tier.

Why do I need Python?

Kai is built with Python and Qt. Setup Kai.cmd uses Python 3.12 once to install Kai's own private copy of its packages; Kai.exe then starts it without a console window.

Does it work with Spotify?

Yes — Music controls any player that shows up in Windows media controls, including Spotify. Lyrics come from LRCLIB when available.

Will it slow my laptop down?

Kai is native, not a browser app. It sleeps as a small pill, animations stop when idle, and music libraries load only while Music is open.

Windows says the app is from an unknown publisher.

Kai.exe is a small unsigned launcher. Choose More info → Run anyway, or read its source in tools/KaiLauncher.cs first.

How do I quit or uninstall?

Right-click the Kai icon in the tray and choose Quit Kai. To uninstall, delete the Kai folder and %LOCALAPPDATA%\Kai.
